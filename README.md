# Manutenção Preditiva com Machine Learning aplicada ao PCM
O que é: Um modelo preditivo desenvolvido em Python para identificar falhas iminentes em equipamentos industriais, visando a transição da manutenção corretiva para a preditiva.  

Tecnologias: Python (Pandas, Scikit-learn, Seaborn).  

Principais resultados:
- Desenvolvimento de modelo Random Forest com 97% de Recall na detecção de falhas.
- Automação da geração de relatórios de risco, exportando uma lista de ativos críticos diretamente para Excel.
- Foco em otimização de disponibilidade de ativos (KPIs de PCM).
